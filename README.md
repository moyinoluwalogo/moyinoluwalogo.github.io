# Website

A personal website hosted on GitHub Pages.

## Description

This repository contains the source code for a personal website built with HTML and CSS. The site is designed to be clean, responsive, and easy to navigate, providing a professional web presence.

## Features

- 📱 Responsive design that works on all devices
- 🎨 Modern and clean user interface
- 🚀 Fast loading times
- 📄 Simple and maintainable codebase

## GitHub Pages

This website is hosted using GitHub Pages. Visit the live site at:
`https://moyinoluwalogo.github.io/Website/`

## Local Development

To view the website locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/moyinoluwalogo/Website.git
   ```

2. Open `index.html` in your web browser

No build process or dependencies required!
